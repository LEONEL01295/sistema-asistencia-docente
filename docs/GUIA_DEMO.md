# Guía de demostración

1. Iniciar el sistema con `npm start`.
2. Abrir `/admin` e iniciar como administrador.
3. Registrar un docente con número de empleado y contraseña inicial.
4. Asignar un horario al docente.
5. Cerrar sesión.
6. Abrir `/docente`.
7. Iniciar sesión con el número de empleado y la contraseña creada.
8. Mostrar el resumen personal, historial, horario, justificantes y cambio de contraseña.
9. Explicar que la base inicia vacía y las asistencias aparecerán al conectar la base institucional.
