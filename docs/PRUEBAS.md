# Pruebas funcionales

- El administrador puede iniciar sesión en `/admin`.
- Una cuenta docente no puede iniciar sesión en el portal administrativo.
- El administrador puede registrar un docente y asignarle contraseña.
- El docente puede iniciar sesión en `/docente` con número de empleado.
- El docente solo recibe su propio dashboard, asistencias, horarios, reportes y justificantes.
- El docente puede cambiar su contraseña.
- El administrador puede restablecer la contraseña del docente.
- La base inicia sin docentes, horarios ni asistencias de demostración.
